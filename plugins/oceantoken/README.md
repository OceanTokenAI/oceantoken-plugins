# OceanToken plugin

One OceanToken account for 500+ AI models inside Codex and Claude Code: search models and
prices, estimate costs, and generate images, video, speech and text.

- MCP server: `https://mcp.oceantoken.ai/mcp` (OAuth sign-in, or an OceanToken API key as bearer token)
- Skills: `oceantoken-media`, `oceantoken-models`, `oceantoken-setup`

Install instructions are in the [repository README](../../README.md).
